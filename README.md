
# CV Web - Nicol Tamara Nieves Quiñonez

Este proyecto es mi CV web profesional, desarrollado como parte de una actividad académica. El objetivo principal fue crear una página web responsive, con buen diseño, información personal y profesional actualizable, enlaces a redes sociales y despliegue mediante Docker.

## Descripción del proyecto

El proyecto consiste en un currículum vitae web donde presento mi perfil profesional, experiencia, habilidades técnicas, proyectos y medios de contacto. La página está diseñada para adaptarse correctamente a diferentes dispositivos como computadoras, tablets y celulares.

Además, el CV cuenta con botones de navegación interna que permiten dirigirse a diferentes secciones como perfil, experiencia, habilidades, proyectos y contacto. También incluye enlaces a mis redes sociales en el pie de página mediante íconos representativos.
